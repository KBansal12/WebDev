🎓 Course Management System (Flask + MySQL)

A simple Course Management System built using **Flask**, **MySQL**, and **HTML/CSS**.

This project includes user registration, login authentication, session handling, and database integration using PyMySQL.

🚀 Features

- 🔐 User Registration (Name, Email, Password)
- 🔑 Secure Login with Hashed Passwords
- 🗄 MySQL Database Integration
- 📊 Dashboard Page
- 🎨 Styled Login & Registration UI
- 🧠 Session Management
- ✅ Unique Email Validation

🛠 Tech Stack

- Backend: Python (Flask)
- Database: MySQL
- Database Connector: PyMySQL
- Frontend: HTML + CSS
- Version Control: Git & GitHub
